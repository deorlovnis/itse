# itse verbs

Generated by `itse verbs --md` for a workspace with only built-ins; `itse verbs` prints the current workspace's index.

| Verb | Arguments | MCP tool | What it does |
|---|---|---|---|
| `status` | `[--hosts]` | `problems_symbols` | the workspace, its items and their states |
| `use` | `<ext> [key=value…]` | `test_build_run` | add an extension to the developer layer |
| `unuse` | `<ext>` | – | remove an extension from the developer layer |
| `install` | `[pkg…]` | `test_build_run` | fetch and verify the pinned packages, as a run |
| `lock` | `[--refresh] [--target V] [pkg]` | `test_build_run` | refresh pins from their sources; installs nothing |
| `ext` | `[list\|show\|tools\|add\|remove] [id]` | `problems_symbols` | list, show, add or remove extensions |
| `env` | `[--sh]` | – | the composed environment |
| `exec` | `[cmd…]` | – | run a command in the composed environment |
| `gc` | `[--keep-locked]` | – | remove unused packages and old results |
| `run` | `<label> [--input V…] [args…]` | `test_build_run` | run a declared action |
| `build` | `[target] [--action V]` | `test_build_run` | build; located problems |
| `test` | `[target] [filter] [--action V]` | `test_build_run` | run tests; failing tests at their lines |
| `problems` | `[scope] [--new] [--all]` | `problems_symbols` | compiler and language server problems |
| `find` | `<name> [--kind V]` | `problems_symbols` | symbols by name |
| `info` | `<name>` | `problems_symbols` | a symbol's signature, docs and location |
| `refs` | `<name>` | `problems_symbols` | references to a symbol, by file |
| `outline` | `<path>` | `problems_symbols` | a file's symbols |
| `show` | `<id> [--page V] [--raw] [--grep V] [--tail V] [--json]` | `show_result` | a stored result or log by id |
| `stop` | `<handle>` | `test_build_run` | stop a server or debug session |
| `cancel` | `<run>` | `test_build_run` | cancel a run |
| `stats` | `[--since V] [--by V] [--json]` | – | the local usage log, summed |
| `verbs` | `[--md] [--json]` | – | the verb index |
| `hook` | `<recipe>` | – | a harness hook; never starts the daemon |
| `mcp` | – | – | the MCP endpoint on stdio |
| `daemon` | `[stop\|restart\|status]` | – | the workspace daemon |

exit codes: 0 ok, 1 the verb reports failure, 2 error, 3 needs a human, 4 running, 130 interrupted

results: the first line is VERDICT verb scope — counts; ids such as run:14/T1 open with 'itse show'

actions: none declared
